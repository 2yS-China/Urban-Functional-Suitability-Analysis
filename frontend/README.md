# 前端极简原型

## 概述

这是一个极简的单页面应用原型，使用纯HTML/CSS/JavaScript实现，无需任何构建工具或复杂框架。

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 基础样式（Flexbox布局）
- **Vanilla JavaScript** - 应用逻辑
- **Leaflet** - 地图引擎（CDN引入）

## 文件结构

```
frontend/
├── index.html          # 主页面（包含所有HTML结构和样式）
├── app.js             # 应用逻辑（约400行）
└── README.md          # 本文档
```

## 启动方式

### 方法1: 使用Python内置HTTP服务器

```bash
cd frontend
python -m http.server 8080
```

然后访问：http://localhost:8080

### 方法2: 使用VS Code Live Server

1. 安装Live Server扩展
2. 右键index.html，选择"Open with Live Server"

### 方法3: 直接打开

某些浏览器支持直接打开HTML文件（可能有CORS限制）

## 前置条件

**必须先启动后端API服务器：**

```bash
cd backend
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

## 使用流程

1. **创建项目**
   - 点击"新建项目"
   - 输入项目名称和描述
   - 点击"创建"

2. **上传数据**
   - 选择项目进入工作区
   - 上传边界数据（必需）
   - 上传POI数据（必需）
   - 上传路网数据（可选）

3. **开始分析**
   - 配置网格大小和缓冲半径
   - 点击"开始分析"
   - 等待分析完成（进度条显示）

4. **查看结果**
   - 统计卡片显示概览
   - 地图显示功能分布（颜色编码）
   - 点击网格单元查看详情

5. **知识问答**
   - 在输入框输入问题
   - 点击"提问"获取答案

## 设计原则

1. **极简主义**
   - 无图标库，使用文本和简单符号
   - 基础颜色方案（蓝色主题）
   - 最小化样式代码

2. **功能优先**
   - 关注核心功能实现
   - 简化交互流程
   - 清晰的状态反馈

3. **易于理解**
   - 单一HTML文件包含所有结构
   - 简单的JavaScript逻辑
   - 最少的外部依赖

## API配置

API基础URL在`app.js`中配置：

```javascript
const API_BASE_URL = 'http://localhost:8000';
```

如需修改，直接编辑此常量。

## 浏览器兼容性

- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+

## 已知限制

1. **无状态持久化**：刷新页面会丢失当前状态
2. **无错误重试**：网络错误需要手动重试
3. **无离线支持**：必须联网使用
4. **基础样式**：未针对移动端优化
5. **轮询任务**：使用2秒轮询，非WebSocket实时推送
