# OpenStreetMap真实数据

## 数据来源
- 坐标范围: N=40.02, S=39.98, E=116.35, W=116.3
- 数据源: OpenStreetMap
- 下载时间: 2026-09-20 12:20:39

## 数据文件
1. **boundary.geojson** - 区域边界
2. **poi.geojson** - 兴趣点数据（1351个）
3. **roads.geojson** - 路网数据（2352条）
4. **water_bodies.geojson** - 水体数据（51个）
5. **green_spaces.geojson** - 绿地数据（384个）

## 数据质量说明
- 这些数据来自开放地图社区，质量取决于当地贡献者的维护情况
- 建议作为测试和演示使用
- 实际项目建议使用政府官方数据或商业数据

## 使用说明
1. 将这些数据上传到系统进行测试
2. boundary.geojson和poi.geojson是必需的
3. 其他数据是可选的，可用于测试对应功能

## 下一步
如需下载更多数据类型（DEM、土壤、灾害风险等），需要使用其他数据源：
- DEM: SRTM、ASTER GDEM
